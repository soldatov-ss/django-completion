# 0.2.9

Documentation and discoverability improvements. No code changes.

## Changes

- **Fix URL inconsistency in `zensical.toml`**: `site_url`, `repo_url`, and `repo_name` used underscores (`django_completion`) while every other reference in the project uses hyphens. Fixed to `django-completion` throughout so the docs site canonical URL and all generated links are consistent.
- **Add missing pages to the docs nav**: `how_it_works.md` and `troubleshooting.md` were fully written but absent from the `zensical.toml` nav, making them unreachable from the sidebar. Both pages are now linked in the nav between Usage and API Reference. `comparison.md` is also added between Installation and Usage.
- **Add comparison page** (`docs/comparison.md`): explains what Django's built-in shell completion provides, where it stops, and what django-completion adds — including a feature-by-feature table. Closes #18.
