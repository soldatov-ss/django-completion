# 0.3.0

The cache becomes a documented contract, and coding agents become its third consumer — alongside bash and zsh Tab completion, which are completely unchanged.

## New

- **`autocomplete context` subcommand**: prints a compact markdown project summary for coding agents — project-local commands first with their non-global flags and help text, migration names per app, then the remaining commands on one line. `--json` prints the full cache instead; `--refresh` forces a rebuild first. The cache is rebuilt automatically when missing or stale (60-second cooldown, same as everywhere else).

- **`command_apps` cache field**: maps each command name to the label of the app providing it (Django built-ins appear as `"django.core"`). Combined with the existing `app_labels` origin (`local`/`pip`), any consumer can now distinguish the project's own commands from built-in and third-party ones. Additive change — `schema_version` stays 2.

- **Cache schema is now a documented public contract**: new "For AI agents" docs page with the field-by-field schema, the file-discovery rule, freshness semantics, and a stability policy — additive fields do not bump `schema_version`, breaking changes do, consumers must ignore unknown fields.

- **Context-file snippet**: README and the agents docs page include a copy-paste block for `AGENTS.md`/`CLAUDE.md` that points agents at the cache instead of `manage.py help` or grepping `management/commands/`.

- **Tab completion for the new subcommand**: `autocomplete <TAB>` now offers `context`, and `autocomplete context --<TAB>` completes `--json` and `--refresh`.

## Changed

- fish shell support moves out of 0.3.0 to the backlog.
