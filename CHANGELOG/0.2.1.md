# 0.2.1

Patch release with five fixes discovered during real-world testing after 0.2.0.

## Fixed

- `autocomplete <TAB>` now completes `install`, `refresh`, `status`, `uninstall` instead of falling through to app labels.
- `migrate <TAB>` lists local apps before pip/Django apps, alphabetically within each group.
- `autocomplete status` cache age is now human-readable (`2 days`, `47 minutes`) instead of raw seconds.
- `autocomplete uninstall` reminds you to `source ~/.bashrc` (or `~/.zshrc`) or open a new terminal to complete removal from the current shell session. The cache-file note is also included.

## Docs

- Added troubleshooting entry for `"Unknown command: 'autocomplete'"`: explains that settings must be loaded before running any `manage.py autocomplete` command, while tab completion itself never imports Django.
