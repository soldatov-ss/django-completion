# 0.2.10

Documentation corrections, ruff tooling fix, two new tests, `status --verbose` UX improvement, expanded Docker/WSL troubleshooting, and release script hardening. No breaking changes.

## Changes

- **Fix `./manage.py` standalone overclaim in docs and README**: `docs/usage.md`, `docs/index.md`, `docs/api.md`, and `README.md` all listed `./manage.py <TAB>` as a supported invocation. The bash template registers completion for `manage.py` only; the path-prefixed form is intentionally out of scope. The wrapped form `python ./manage.py` is supported and remains in the docs.

- **Fix stale "v1 fallback" completion-depth description**: `docs/usage.md` and `README.md` said unknown commands receive "app labels plus option flags." Since 0.2.2, commands absent from `_COMMAND_RULES` receive options only. Updated to "option flags for all commands; app labels for explicitly-taught commands."

- **Fix shell detection order in troubleshooting docs**: The "Wrong shell was detected" section said `$ZSH_VERSION` is checked before `$BASH_VERSION`. The actual order (since 0.2.6-1) is `$BASH_VERSION` first, because `$ZSH_VERSION` can be inherited by a bash child spawned inside a zsh session.

- **Exclude `demo/**` from ruff lint**: `demo/` contains generated Django migration boilerplate that produces 14 spurious `RUF012` violations. Added `demo/**` to `lint.exclude`; `uv run ruff check .` now exits clean.

- **Add comparison page to Getting Started list**: `docs/index.md`'s numbered list now includes `comparison.md` as entry 6. Previously it was only linked from the "Why it exists" paragraph at the bottom.

- **Document `$PWD` cache lookup requirement**: Added as the first check in the "Tab completion shows nothing" troubleshooting section, and as a tip in `docs/usage.md`. Cache lookup walks up from `$PWD`; completion silently returns nothing if the terminal is outside the project tree.

- **New bash subprocess tests**: Two tests added to `tests/test_shell.py`: `uv run python manage.py migrate myapp <TAB>` reaches migration names; empty `COMPREPLY` is verified for an unknown command even when files exist in the working directory.

- **`status --verbose` source reminder**: When a shell's hook is installed and its script is current, `status --verbose` now prints `If completion is not active in this session, run: source <rc_path>`. This covers the most common post-install confusion point.

- **Expanded Docker and WSL troubleshooting**: Docker section now includes `docker exec` and `docker compose exec` examples for rebuilding the cache inside a running container. A new WSL subsection explains that the hook must be installed in the WSL shell and that `$PWD` must be inside the mounted project directory.

- **Release script pre-flight checks**: `scripts/release.py` now verifies a clean working tree, a non-empty changelog entry, and passing tests before running `git tag`. Each failed check prints a clear message and exits. Removed stale TODO comments.

- **Track demo project**: `demo/` (the Django project used to record the demo GIF) is now committed to the repository.

- **Fix PyPI demo image**: `README.md` now uses an absolute GitHub raw URL for `demo.gif` so PyPI renders it correctly.
