# 0.2.6

Regression fix for shell detection introduced in 0.2.5.

## Fix

- **Shell detection priority order**: `_detect_shell()` in 0.2.5 checked `$ZSH_VERSION` before `$BASH_VERSION`. This caused a regression: when bash is spawned inside a running zsh session, bash inherits `$ZSH_VERSION` from the parent process but also sets its own `$BASH_VERSION`. The old priority returned `"zsh"` — and pointed `autocomplete install` at `.zshrc` — even though the actual running shell was bash.

  Fix: check `$BASH_VERSION` first. It is always set by the currently running bash and cannot be a stale inherited value from a non-bash parent (zsh never sets `$BASH_VERSION`). `$ZSH_VERSION` remains as the next fallback for pure-zsh sessions, followed by `$SHELL`.
